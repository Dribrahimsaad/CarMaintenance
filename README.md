نظام إدارة وصيانة السيارات المتكامل 
Car Maintenance Management System

 مصمم خصيصاً لمساعدة مالكي السيارات ومسؤولي الأساطيل على متابعة صيانات السيارات بدقة واحترافية عالية، مع دعم كامل للغتين العربية والإنجليزية
✨ المميزات الرئيسية Features

    🛠️ تسجيل وصيانة شاملة: تتبع دقيق لصيانات (زيت وفلتر المحرك، مياه الراديتير، الكاوتش، بطارية السيارة، التيربو، السيور، الفلاتر، والفرامل)، بالإضافة إلى خانة مخصصة للصيانات الأخرى والملاحظات.

    🔔 نظام التنبيهات الذكي: فحص تلقائي لمواعيد الصيانة القادمة وعدادات الكيلومترات عند تشغيل البرنامج لتنبيه المستخدم بالصيانات المستحقة.

    📖 الشاشة الإرشادية ودليل الكيلومترات: دليل مرجعي مدمج داخل البرنامج يوضح مواعيد ومسافات الكيلومترات القياسية لكل نوع صيانة للحفاظ على كفاءة السيارة.

    📋 سجل الصيانة الشامل: عرض جميع العمليات السابقة مع إمكانية التعديل السريع والتحديث الفوري للبيانات.

    📊 التصدير والاستيراد المتقدم:

        تصدير السجلات والتقارير إلى ملفات Excel / CSV أو تقارير نصية TXT.

        تصدير واستيراد قواعد البيانات بالكامل (SQLite Backup & Restore) لحماية البيانات.

    🌐 واجهة ثنائية اللغة: دعم كامل للتبديل الفوري بين اللغتين العربية والإنجليزية.
